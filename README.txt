FAKE NEWS DETECTION - CLASS XII AI PROJECT (843)  [corrected version]

FILES
- generate_data.py : creates data/news_samples.csv (200 invented examples built from 64 sentence templates).
- data/news_samples.csv : columns text, label, template_id (REAL-style = official notices, FAKE-style = rumours).
- train_model.py : TF-IDF + Logistic Regression. Removes duplicates, splits BY TEMPLATE so test patterns are unseen,
                   runs 5-fold grouped cross-validation, saves the model AND evaluation_results.json.
- evaluation_results.json : written by train_model.py (do not edit by hand).
- app.py : Streamlit interface.
- models/fake_news_pipeline.joblib : trained model (created by train_model.py).
- requirements.txt : Python dependencies.

RUN (in this order)
1. pip install -r requirements.txt
2. python generate_data.py
3. python train_model.py
4. streamlit run app.py

WHAT CHANGED FROM THE FIRST VERSION
- The old CSV had 120 rows but only 46 unique sentences, so the same sentence appeared in both train and test.
  That produced a misleading 100% accuracy. This is fixed.
- generate_data.py and the dataset now match (before: script made 480 rows, CSV had 120).
- The evaluation file is now generated by the training script.
- Added "hard" examples: real-style notices that mention rumours, and fake-style text with official wording.

HOW TO READ THE RESULTS
- The single hold-out test (unseen templates) gives a lower, more realistic score than before.
  With so few templates, this number changes a lot depending on which templates land in the test set.
- Grouped cross-validation (mean +/- std) is the more stable figure to quote.
- Neither number measures real-world fake-news detection: the data is invented and the labels are teaching labels.

IMPORTANT
This prototype learns language patterns. It does NOT check facts, sources, dates or images.
For a stronger project, replace the CSV with a properly sourced, licensed, fact-checked dataset
(for example a Kaggle fake/real news dataset), document its source, and test on separate data.
Never invent interview feedback or test results.
